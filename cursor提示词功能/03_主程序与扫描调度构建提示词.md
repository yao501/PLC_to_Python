# 主程序与扫描调度构建提示词

> 用途：在基础原语功能块和业务功能块都逐步迁移完成后，构建 Python 侧主程序、统一扫描调度逻辑和全局数据流。  
> 典型对象：CFC 主程序、总控调度器、Controller / MainProgram。  
> 建议：先贴 `00_项目级总前置提示词.md`，再贴本提示词，最后贴主程序相关材料。

```text
请在严格遵守“项目级总前置提示词”的前提下，构建整个 Python 侧的主程序与扫描调度逻辑。

当前任务目标：
基于已经迁移完成的基础原语功能块和业务功能块，构建主程序 / Controller / MainProgram，并实现统一的 PLC 扫描调度模型。

要求：

1. 严格复用已经存在的 Python 功能块实现，不要重写其内部逻辑。
2. 当前任务重点是：
   - 主程序结构
   - 实例初始化
   - 扫描周期调度
   - 调用顺序
   - 中间变量传递
   - 输入输出刷新
   - 联锁和优先级关系
3. 主程序统一采用 step(dt, inputs) 之类的入口。
4. 所有功能块实例都要在主程序中被有序调度。
5. 如果某些顺序来自 CFC 连线，请按连线和信号流重建。
6. 如果某些顺序不明确，请基于合理假设给出最佳可行版本，并明确说明。
7. 不要把主程序写成一次性脚本。
8. 要让整个系统具备“周期调用一次 -> 所有状态推进一次”的运行模型。
9. 尽量保留原始变量名和结构语义。
10. 输出应尽量完整、可运行、可扩展。

请按以下结构输出：

1. 你对主程序 / CFC 调度结构的理解
2. 整体调度设计说明
3. Python 主程序代码
4. 功能块实例初始化代码
5. step(dt, inputs) 的调用顺序说明
6. 中间变量与数据流说明
7. 输入刷新 / 输出生成逻辑说明
8. 风险点、假设和待确认项
9. 如有必要，给出最小运行示例

可用信息如下：
[在这里粘贴主程序涉及的功能块名单、变量表、CFC 连线关系、局部顺序说明、已经迁移好的 Python 类名]
```

---

## 推荐输入材料顺序

建议按下面顺序提供材料：

1. 主程序涉及的功能块名单
2. 已经迁移完成的 Python 类名
3. 变量表
4. CFC 连线关系
5. 局部或全局执行顺序说明
6. 输入输出说明
7. 补充限制与待确认项

---

## 适用范围提示

当你已经具备：

- 一批基础原语功能块
- 一批业务功能块 / 组合块
- 比较明确的主程序信号流

再使用本提示词最合适。

如果当前还只是单个业务块或局部小逻辑，请优先使用：
- `02_业务基础块与组合块迁移提示词.md`
