【总原则】
1. 所有基础原语块都必须保持 PLC 扫描周期语义、跨周期状态保持、统一主程序调度。
2. 不要擅自优化、重构或改变业务行为。
3. 若 IEC 标准语义、CODESYS 实现习惯、工程安全策略之间存在差异：
   - 基础块优先保持标准/常见 PLC 语义
   - 系统安全要求放到主程序输出门控层处理
4. 所有假设、风险点、待确认项都要明确列出。

【R1 时间单位风险处理】
1. 内部时间统一使用整数时间单位，不使用 float 秒累积。
2. 推荐统一为 int 毫秒：
   - dt_ms
   - PT_ms
   - ET_ms
3. 对外接口如需接收秒或其它形式，必须先转换为整数毫秒后再进入功能块。
4. 所有定时器比较统一使用整数比较：ET >= PT。
5. 定时器内部禁止使用 ET += dt_float 之类的浮点累积实现。
6. 默认将 ET 饱和到 PT，避免无限增大。

【R2 RESET / EN / ENO 风险处理】
1. 不要给标准基础块默认添加 RESET 端口。
2. 不要把 EN / ENO 直接混入基础块本体接口。
3. 若源工程在 CFC/FBD 层依赖 EN / ENO：
   - 在主程序/调度层实现调用门控
   - EN=False 时，该块本周期不执行
   - 是否保持上次输出值，按源工程调用语义处理
4. 基础块本体保持简洁、标准、可复用。

【R3 R_TRIG / F_TRIG 冷启动风险处理】
1. 基础块继续按“依赖上一周期状态”的边沿检测模型实现。
2. 但冷启动防误动作不由基础块单独承担，而由主程序统一保证。
3. 项目级强制规则：
   - system_ready=False 时，边沿脉冲不得直接形成物理输出动作
   - 只有 system_ready=True 之后产生的有效边沿，才允许参与最终动作
4. 冷启动前已经为真的启动命令，默认不视为有效启动命令；必须在 system_ready=True 后重新产生一次边沿，才允许动作。
5. 在测试中必须覆盖：
   - 冷启动首拍 CLK=False
   - 冷启动首拍 CLK=True
   - system_ready=False 时边沿出现
   - system_ready=True 后首次有效边沿出现

【R4 SR / RS 语义风险处理】
1. SR / RS 必须按电平锁存语义实现，而不是边沿锁存。
2. SR 为置位优先。
3. RS 为复位优先。
4. 如果业务场景需要“边沿触发后锁存”，必须通过：
   - R_TRIG/F_TRIG + SR/RS
   的组合方式实现，不能修改 SR/RS 本体语义。
5. 必须补充真值表测试：
   - S=0,R=0
   - S=1,R=0
   - S=0,R=1
   - S=1,R=1
6. 明确验证：
   - SR 在 S=1,R=1 时置位优先
   - RS 在 S=1,R=1 时复位优先

【R5 浮点精度风险处理】
1. R5 与 R1 合并处理：彻底禁止浮点时间累积。
2. 所有定时器内部使用整数时间累计或扫描计数。
3. 若扫描周期固定，可采用：
   - tick_count += 1
   - ET_ms = tick_count * cycle_ms
   的方式实现。
4. 必须补充长周期测试：
   - 1000 周期
   - 10000 周期
   - 阈值前后边界周期
5. 验证定时翻转边界不漂移。

【R6 dt 来源风险处理】
1. 项目默认采用固定扫描周期模式。
2. dt 来源于主程序/任务配置周期，不来源于 Python 实际运行耗时。
3. 禁止基础块内部自行读取系统时钟。
4. 主程序统一入口采用 step(dt_ms, inputs)。
5. 主程序统一顺序为：
   - 输入刷新
   - 功能块推进
   - 中间 request 计算
   - 最终输出门控
   - 输出刷新
6. 可额外保留 simulation/debug mode，允许外部传入变化 dt，但默认生产语义必须是固定扫描周期。

【系统级输出安全规则（强制）】
1. 所有业务逻辑先产生命令请求 request，不直接写物理输出。
2. 所有物理输出统一经过以下门控后再生成：
   final_output = system_ready AND output_enable AND safety_ok AND interlock_ok AND request
3. system_ready=False 时，所有物理输出默认强制关闭。
4. 上电后至少保留一个稳定窗口；稳定窗口内不允许物理输出动作。
5. 边沿脉冲可以在内部逻辑层存在，但在 system_ready=False 时不得直接驱动设备。
