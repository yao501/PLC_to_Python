# 业务基础块与组合块迁移提示词

> 用途：迁移业务功能块、设备基础块、小范围组合逻辑。  
> 典型对象：电机启停保持、阀门控制、报警延时、自动/手动切换、故障锁存、局部设备单元逻辑。  
> 建议：先贴 `00_项目级总前置提示词.md`，再贴本提示词，最后贴本轮输入材料。

```text
请在严格遵守“项目级总前置提示词”的前提下，将下面这段 CODESYS 功能块 / ST 逻辑 / 局部组合逻辑迁移为 Python。

当前任务目标：
迁移业务基础块或局部组合块。
请在 Python 中保持其 PLC 周期行为、状态保持、输入输出更新顺序和逻辑语义一致。

要求：

1. 严格复用已经迁移完成的基础原语功能块，例如：
   - TON
   - TOF
   - TP
   - R_TRIG
   - F_TRIG
   - SR
   - RS
2. 不要重复实现这些公共原语，除非我明确要求你重写。
3. 功能块优先映射为 Python 类。
4. 必须体现跨周期状态保持。
5. 必须正确处理：
   - 定时器行为
   - 边沿触发
   - 锁存 / 复位逻辑
   - 输入输出更新顺序
6. 迁移目标不是逐字翻译，而是在明确运行契约下保持行为一致。
7. 如该逻辑属于多个原语块组合，请明确说明组合关系。
8. 不要擅自优化或改变业务行为。
9. 若发现潜在 bug、歧义、优先级不明确等问题，可以标记，但不要私自修改业务语义。
10. 输出尽量为可运行的 Python 代码，而不是伪代码。

请按以下结构输出：

1. 先说明你对该业务块 / 组合块的逻辑理解
2. 说明它依赖了哪些基础原语块
3. 给出 Python 实现
4. 给出 step(dt, ...) 的调用示例
5. 判断它属于：
   - 组合逻辑
   - 时序逻辑
   - 混合逻辑
6. 说明关键状态、输入输出、时序行为
7. 列出风险点、假设和待确认项
8. 如有必要，补一个最小测试示例

原始内容如下：
[在这里粘贴业务功能块、变量表、ST 代码、接口定义、补充说明]
```

---

## 推荐输入材料顺序

建议按下面顺序提供本轮材料：

1. 变量表
2. FB / FUNCTION / PROGRAM 接口定义
3. ST 代码
4. 补充行为说明
5. 该块依赖的已完成基础原语块名称

---

## 适用范围提示

本提示词适合：

- 单个业务功能块
- 由多个基础原语块构成的较小业务块
- 一个局部设备功能段
- 一个局部流程段的控制逻辑

如果已经涉及全局调度、实例初始化、统一扫描入口、跨多个设备单元的大规模连接关系，更适合使用：
- `03_主程序与扫描调度构建提示词.md`
